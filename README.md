# 📁 File Uploading System using Flask & MongoDB

This project is a simple and efficient **File Uploading System** built using **Flask (Python)** as the backend and **MongoDB** for storing user data.
It allows users to **sign up, log in, upload files**, and securely manage them with a clean and user-friendly interface.

### 🚀 Features

* 🔐 **User Authentication** – Signup & Login using MongoDB
* 📤 **Upload Files Directly** from the web interface
* 📄 **View & Manage Uploaded Files**
* 🔒 **Secure Logout System**
* 🧹 **Clean UI with HTML & CSS**

### 🛠 Tech Stack

* **Python (Flask Framework)**
* **MongoDB (Compass)**
* **HTML5, CSS3**
* **Bootstrap (Optional)**

### 📦 How It Works

1. User signs up using email & password
2. Logs in and gets access to the dashboard
3. Uploads any file directly
4. Logout button securely ends the session

### 📘 Project Goal

A beginner-friendly project to understand Flask authentication, file handling, session management, and MongoDB database integration.
